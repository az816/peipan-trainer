# 配盘实训台

**给装配电工新手的看图接线练习台**：在浏览器里对着电气图纸接线、校线、送电试车、找故障，元器件按实物画，一眼能和现场对上。

**在线使用：https://az816.github.io/peipan-trainer/**　也可以下载后双击 `index.html`，手机、平板、电脑都能练。

> 本软件只用于学习看图和接线思路。真实接线必须断电、验电、挂牌，遵守安全规程，在有资格的人员指导下进行。

## 适合谁

- 刚入行的自动化 / 控制柜装配电工，看不懂图纸、不知道线从哪接到哪
- 准备考电工证（低压电工作业、电工职业技能等级）想多练实操思路的人
- 带徒弟的师傅：可以打印任务卡，让徒弟先在软件上接对，再上实物练习板

## 能练什么

- **看图接线仿真**：32 道题，从点动、自锁、正反转、星三角，到 PNP/NPN 传感器、PLC、电磁阀、急停、安全继电器、安全光栅、步进、伺服、阀岛、4–20mA 模拟量。点端子连线，接错当场提示原因。
- **送电试车**：按步骤按按钮、看接触器吸合、电机转向、PLC 指示灯，电流沿线流动；短路、缺相、接反都会表现出来。
- **排故**：随机藏一处故障（断线、触点粘连、线圈烧坏、传感器坏），用万用表量，在图纸上点出位置、说出类型。
- **11 节动手课**：回路与短路、安全三件事、符号↔实物↔端子、万用表档位和插孔、中间继电器认脚、电机接线盒星 / 角连接片、剥线压端子套线号、PE/0V/屏蔽线、电压法排故、看懂多页图纸、送电对点（PLC I/O 点检）。
- **配柜实战**：5 套图纸由易到难（★ 水泵启停箱、★★ 提升机正反转箱、★★★ 输送线 PLC 柜、★★★★ 风机星三角柜、★★★★★ 恒压供水变频柜），每套都要看主回路 + 控制回路图 → 选元件 → 上导轨布置 → 定导线截面、颜色、线槽 → 验收打分。
- **知识库**：识图入门、柜体布局规范、PLC 与通讯（梯形图、故障灯、HMI 变量、PROFINET、变频器、西门子 / 三菱对照）、选型计算、术语表、入行准备（证书、工具、练习板）。
- **测验**：55 题题库 + 每日 5 题 + 错题本，选项每次打乱，不能靠蒙。

## 学习路线（9 关）

| 关 | 内容 |

## 怎么打开

- 或者在本目录运行 `python -m http.server 8765`，浏览器打开 http://127.0.0.1:8765
- 在线版：https://az816.github.io/peipan-trainer/ （GitHub Pages，推送到 `main` 后几分钟自动更新）

## 技术说明

纯 HTML + CSS + 原生 JavaScript，没有框架、不需要编译、不依赖后端。电路仿真、元器件绘图、题库都在 `js/` 里，`node tests/run.js` 会自动检查每道题的标准接法能否试车通过、故障能否被查出、题库有没有“选最长的就对”的毛病。技术内容的核对记录见 `docs/research/content-review.md`，以国标和厂家手册为准。

## 加一个新练习

在 `js/exercises.js` 的 `BASE` 里加一项（设备、线号 nets、原理图 sch、试车步骤 test），再加到 `PP.EX` 列表。然后运行 `node tests/run.js`：它会检查端子是否存在、设备是否重叠、标准接法能否试车通过、随机故障能否被发现。

## 加题注意

选择题由 `PP.quizBox` 显示，每次都会打乱选项顺序；配柜实战的选型题打开页面时打乱一次。写题时错误选项要用新手真会犯的错，长度和正确答案差不多。`node tests/run.js` 会检查题库：正确答案是唯一最长选项的题不能超过 20%。

## 加一套配柜图纸

在 `js/build-data.js` 里照现有的写法 `PROJ.push(mk({...}))`：任务书 `task`、选型 `sel`、元件 `parts`、参考布置 `answer`、布置规则 `rules`（用 `RULE.first / chain / group / apart / next / rightOf / row / bottom / bottomOnly` 组合）、走线 `wires`；主回路图加在 `js/pages-build.js` 的 `MAINS` 里，控制回路用 `ctrlEx` 指向接线实训里的一道题。再在 `js/progress.js` 的学习路线里放一项 `{ t: 'build', id }`。`node tests/run.js` 会检查参考答案是不是满分。
