# 配盘实训台

**给装配电工新手的看图接线练习台**：在浏览器里对着电气图纸接线、校线、送电试车、找故障，元器件按实物画，一眼能和现场对上。

**在线使用：[az816.github.io/peipan-trainer](https://az816.github.io/peipan-trainer/)**

也可以下载后双击 `index.html`，手机、平板、电脑都能练。

> 本软件只用于学习看图和接线思路。真实接线必须断电、验电、挂牌，遵守安全规程，在有资格的人员指导下进行。

## 适合谁

- 刚入行的自动化 / 控制柜装配电工，看不懂图纸、不知道线从哪接到哪
- 准备考电工证（低压电工作业、电工职业技能等级）想多练实操思路的人
- 带徒弟的师傅：可以打印任务卡，让徒弟先在软件上接对，再上实物练习板

## 能练什么

- **看图接线仿真**：新手路线只练最核心的继电控制，由易到难——点动 → 自锁 → 两地控制 → 电机主回路 → 正反转 → 星三角，外加 4 道实战排故。点端子连线（也可以从端子拖到端子），接错当场标出来，并给出「撤销 / 改接 / 看图 / 为什么」。
- **手机也能练**：图纸 / 盘面 / 任务三个页签，底部常用按钮；双指缩放，按住不放出放大镜，手指附近的端子自动吸附，端子挤在一起时弹出让你选。
- **送电试车**：按步骤按按钮、看接触器吸合、电机转向、PLC 指示灯，电流沿线流动；短路、缺相、接反都会表现出来。
- **排故**：随机藏一处故障（断线、触点粘连、线圈烧坏），按“看现象 → 量 → 判断 → 自己修 → 复测 → 试运行”走完才算修好。
- **7 节动手课**：回路与短路、安全三件事、符号↔实物↔端子、万用表档位和插孔、剥线压端子套线号、电机接线盒星 / 角连接片、电压法排故。
- **配柜实战**：3 套纯继电控制的柜子由易到难——★ 水泵启停箱、★★ 提升机正反转箱、★★★ 风机星三角柜。每套都要看图纸（主回路 + 控制回路）→ 选元件 → 上导轨布置 → 定导线截面、颜色、线槽 → 验收打分；练熟了开「考核模式」，不给提示、交卷才出分。
- **知识库**：识图入门、柜体布局规范、选型计算、术语表、入行准备（证书、工具、练习板）。
- **测验**：32 题基础题库（识图、接线、布局、安全、选型）+ 每日 5 题 + 错题本，选项每次打乱，不能靠蒙。

> PLC、传感器、伺服、变频器等进阶内容先从新手版里拿掉了，数据还留在代码里（`PP.ALL_EX`、`PP.ALL_BUILDS`、`PP.ALL_QZ`），完整版在 git 标签 `archive/full-v1`。

## 学习路线（8 关）

| 关 | 内容 |
|---|---|
| 0 | 安全与电路基础 |
| 1 | 认识元件和图纸符号 |
| 2 | 万用表 |
| 3 | 点动与自锁（剥线压端子套线号，配柜：水泵启停箱） |
| 4 | 两地控制 |
| 5 | 主回路与正反转（配柜：提升机正反转箱） |
| 6 | 星三角降压启动（电机接线盒，配柜：风机星三角柜） |
| 7 | 故障排查（松手就停、乙地停不下来、电机反转、一按反转就跳闸） |

每道接线题按“读图题 → 看演示 → 跟着接 → 独立接 → 考核”五步练，第一次进来有 5 步新手引导。首页每一项分三种状态：没学 · 学过 · 会了（独立接对才算会了）。进度只存在本机浏览器里，不上传任何数据。

## 技术说明

纯 HTML + CSS + 原生 JavaScript，没有框架、不需要编译、不依赖后端。电路仿真、元器件绘图、题库都在 `js/` 里，`node tests/run.js` 会自动检查每道题的标准接法能否试车通过、故障能否被查出、题库有没有“选最长的就对”的毛病。技术内容的核对记录见 `docs/research/content-review.md`，以国标和厂家手册为准。

性能约定（改接线页时请遵守）：

- 动画只动 `transform` / `opacity`，不用 `width / height / top / left` 做动画；电流、闪烁画在单独的浮层 `<svg>` 上。
- 盘面分层（静态 / 元件 / 导线 / 端子），一帧最多画一次，每层只在内容变了时才写 DOM；时间继电器计时时只重画 KT 自己。
- 缩放平移时只改相机层的 `transform`（挂 `will-change`），松手后写回 `viewBox` 并去掉 `will-change`；吸附圈的发光用固定的 `drop-shadow`，只在显示时挂 `will-change`。
- 手势移动用 `requestAnimationFrame` 合帧，存档防抖 300ms，页面关闭时立即保存。
- 每道题一个会话，切题时统一中止手势、取消帧和定时器、断电。

验收结果见 `docs/perf-report.md`。

## 加一个新练习

在 `js/exercises.js` 的 `BASE` 里加一项（设备、线号 nets、原理图 sch、试车步骤 test），再加到 `PP.EX` 列表；要出现在新手路线里，还要把 id 加进 `PP.CORE_EX`，并在 `js/progress.js` 的某一关里放一项。然后运行 `node tests/run.js`：它会检查端子是否存在、设备是否重叠、标准接法能否试车通过、随机故障能否被发现。

## 加题注意

选择题由 `PP.quizBox` 显示，每次都会打乱选项顺序；配柜实战的选型题打开页面时打乱一次。写题时错误选项要用新手真会犯的错，长度和正确答案差不多。`node tests/run.js` 会检查题库：正确答案是唯一最长选项的题不能超过 20%。

## 加一套配柜图纸

在 `js/build-data.js` 里照现有的写法 `PROJ.push(mk({...}))`：任务书 `task`、选型 `sel`、元件 `parts`、参考布置 `answer`、布置规则 `rules`（用 `RULE.first / chain / group / apart / before / next / rightOf / row / bottom / bottomOnly` 组合）；配电类的柜子可以用 `tables` 放回路表，主图用 `slMain` 画单线系统图、走线 `wires`；主回路图加在 `js/pages-build.js` 的 `MAINS` 里，控制回路用 `ctrlEx` 指向接线实训里的一道题。再在 `js/progress.js` 的学习路线里放一项 `{ t: 'build', id }`。`node tests/run.js` 会检查参考答案是不是满分。
