## 一、需要修改（按严重程度排序）

### 1. 【高】热继电器整定倍数“1.0–1.2 倍”偏大，会把人教错

| 位置 | 现在写的 |
|---|---|
| `js/info.js:15` | 整定电流按电机额定电流的 **1.0–1.2 倍**调 |
| `js/pages-data.js:60` | 整定电流按电机额定电流 **1.0–1.2 倍**调 |
| `js/pages-data.js:113` | `set: [Iph, Iph * 1.2]` |
| `js/pages-data.js:152`（PP.QZ 选型题） | 正确选项是“1.0–1.2 倍” |
| `js/pages.js:197` | 表头“整定电流（1.0–1.2 倍）” |
| `js/pages.js:198` | “一般整定在额定电流的 1.0–1.2 倍” |

**应改为**：整定电流**等于电机铭牌额定电流**（一般取 0.95–1.05 倍，不超过 1.05 倍）。起动困难、环境特殊时再按厂家样本调整。测验题选项改成“约 1.0 倍（0.95–1.05）”，`set` 改为 `[Iph*0.95, Iph*1.05]`，`setRec` 保持 1.0×Iph（现在是 1.05×，也可以接受）。

**理由**：热继电器按 IEC 60947-4-1 / GB/T 14048.4 的动作特性设计：1.05×整定值时 2 h 内不动作，1.2×整定值时 2 h 内动作（JR36 样本写的是 1.25×）。整定已经包含了这段余量。如果再把整定值调到 1.2×In，电机要到大约 1.2×1.2≈1.44×In 才保证跳闸，长期过载会烧绕组。西门子星三角说明书也写明，热继电器整定值无论如何不能超过电机电流（星三角时是相电流）。

**来源**：
- Schneider FAQ FA286067（标准规定 1.2×Ir 2 h 内动作）：https://www.se.com/us/en/faqs/FA286067/
- 正泰 JR36 使用说明书 4.2 保护特性（1.05 倍 2 h 不动作，并标注符合 GB/T 14048.4、IEC 60947-4-1）：https://wmsc.lcsc.com/wmsc/upload/file/pdf/v2/lcsc/2211031500_CHINT-JR36-20-20-32A_C5151296.pdf
- Siemens 星三角起动器说明书（“Under no circumstances should the relay be set higher than phase current”）：https://assets.new.siemens.com/siemens/assets/api/uuid:4f737069-0fa7-4754-8f82-c11d31081a2e/industrial-asd-75-132kw-operating-instruction.pdf
- “0.95–1.05 倍”属于国内教材和工程上的常用说法，没有查到具体条文号。

### 2. 【高】星三角热继电器“装在三角形回路”的说法不准确

- `js/pages.js:210` 现在写的是：`选整定范围 … 的热继电器（装在三角形回路，按相电流）`。
- **应改为**：“热继电器装在主接触器后面、接电机 U1/V1/W1 的绕组（相电流）回路里，整定为 0.58×In。如果装在主接触器前面的电源进线上（线电流），就整定为 1.0×In。”
- **理由**：0.58 倍只适用于热继电器流过绕组相电流的接法。“三角形回路”容易被理解成接在三角形接触器 KM3 那一路。那样星形起动期间热继电器没有电流流过，起动过程就失去了过载保护。看错安装位置再按 0.58 倍整定，会导致保护失效。
- **来源**：上面的 Siemens 星三角说明书；WEG RW 热继电器样本（“only 0.58 × motor current flows through the main contactor in wye-delta”）：https://www.wolfautomation.com/content/weg-overloadrelay-rw-catalog-18.pdf

### 5. 【中】导线载流量表 PP.AMP 大截面偏大，环境温度的写法也不对

- `js/pages-data.js:96`：`[10,50],[16,65],[25,100],[35,125],[50,150]`。
- `js/pages.js:151`：“环境 **30°C** 参考值”。
- **问题**：
  - 柜内导线按 GB/T 5226.1 表 6 算，基准环境温度是 **40°C**，不是 30°C。

- **来源**：
  - IEC 60204-1:2016 / GB/T 5226.1-2019 表 6（40°C）。表中 E 列 1.5/2.5/4 mm² = 16.1/22/30 A，经 Kollmorgen 页面印证：https://www.kollmorgen.com/content/strombelastbarkeit-0 。B1 列的具体数值**未能取得原文逐项核对**，是按记忆整理的，改表前请购标准核对。

## 二、建议补充（不算错误，但值得补的现场要点）

1. **西门子和三菱的“源型 / 漏型”叫法正好相反**（建议加在 `js/info.js:6` 的 PLC 卡片里）：
   - S7-1200 手册里，“漏型输入（sinking）”是 1M 接 M（0 V），用来接 PNP 传感器；“源型输入（sourcing）”是 1M 接 +24 V，用来接 NPN。原文为“For sinking inputs, connect '−' to 'M'. For sourcing inputs, connect '+' to 'M'.”（《S7-1200 系统手册》CPU 1214C 接线图注②，文档 109797241，经检索摘要转引）。
   - 三菱 FX3U / FX3G / FX3S 等型号：**漏型输入接 NPN，S/S 接 24V 端子**；**源型输入接 PNP，S/S 接 0V 端子**（三菱官方 FAQ：https://fa-faq.mitsubishielectric.com/faq/show/22255 ）。FX5U 也用 S/S 端子做同样的切换，但**本次没有查到 FX5U 的官方原文**。
   - 两家的物理规则其实一样：**PNP 公共端接 0V，NPN 公共端接 24V**。所以口诀不变，只是名称别混用。
2. **实物端子标识**：S7-1200 V4 机身上印的是 `DI a.0`、`DQ a.0`，程序里的地址才是 `%I0.0`、`%Q0.0`。1214C DC/DC/RLY 的继电器分两组：**1L 管 DQ a.0–a.4，2L 管 DQ a.5–b.1**（检索到的接线图摘要文字有乱码，**以手册为准**）。练习里 Q0.1 放在 2L 组已经注明“做了简化”，可以再写明真实分组。
3. **MAINT 灯**：S7-1200 的 MAINT **闪烁**表示插入了存储卡，CPU 会转入 STOP，需要切换模式或断电重启（经 PLCTalk 引用手册确认：https://www.plctalk.net/threads/siemens-s7-tia-v16-what-colour-should-run-stop-light-be.136477/ ）。`pages-data.js:247` 写的“MAINT 常亮 = 有 I/O 被强制”在 S7-1200 上**未能证实**（S7-1500 是这样）。建议补一条“插卡闪烁”，强制那一条加上“以手册为准”。另外 RUN/STOP 其实是**一个灯**变色（绿 = RUN，黄 = STOP，绿黄交替闪 = 启动中），`info.js:6` 写成“RUN 绿 / STOP 黄”像是两个灯，可以改一下措辞。
4. **HMI 变量避开 MB0 / MB1**：TIA Portal 启用时钟存储器时默认用 **MB0**（M0.0 是 10 Hz 闪烁位），系统存储器常用 MB1。练习里触摸屏按钮用 `%M0.0`，现场一旦启用了时钟位，按钮就会自己闪烁。建议提醒：“HMI 按钮从 MB10 以后开始用，或者用 DB 变量。”（时钟字节默认 MB0 有多个来源一致：https://industrialmonitordirect.com/blogs/knowledgebase/s7-1200-system-and-clock-memory-bits-configuration-guide ，属二手来源；系统字节默认 MB1 **未能证实**。）另外可以加一句：新项目推荐用 DB 里的变量，HMI 按钮不能用于急停或点动这类安全动作。
5. **PROFINET 设备名完整规则**（`pages-plc.js:30` 只写了小写字母、数字、短横线）：总长不超过 240 个字符，用“.”分段，每段不超过 63 个字符；只能用 a–z、0–9、“-”和“.”；每段不能以“-”开头或结尾；不能是 n.n.n.n 这种像 IP 地址的形式；不能以“port-xyz”开头。来源：https://docs.cognex.com/isvs_2520/web/EN/Help_ISVS/Content/Topics/utilities/industrial-ethernet-profinet.htm 、https://us.profinet.com/profinet-addressing-parameters/ （依据 IEC 61158-6-10）。
6. **CJX2-xx10 只有一个常开辅助触点**：正反转、星三角的互锁要用常闭，需要选 CJX2-xx01，或者加装 F4 辅助触头组。加装后的端子号一般是 53-54 / 61-62 这类，不是 21-22，接线时要看实物上的标号。建议加在 KM 卡片（`info.js:5`）里。
7. **电流估算以铭牌为准**：`calcMotor` 固定用 cosφ=0.85、η=0.88，对小电机估得偏低。0.75 kW 四极电机实际约 2 A，程序算出来是 1.5 A，选型页的整定表（0.75–4 kW）会因此偏小。建议加提示：“热继电器按**电机铭牌电流**整定，小电机功率因数和效率更低，电流往往大于 2 A/kW。”（具体样本数据**未能取得**，属经验。）
8. **星三角补充**：
   - 只有铭牌写“380 V △”的电机才能用星三角起动。
   - 切换时间要按负载加速时间整定，常见 4–10 s，练习里用 3 s 只是演示（具体经验公式**未能证实**）。
   - 当前控制回路里，转为三角形运行后 KT 线圈一直通电。很多标准图会在 KT 线圈回路串 KM3 常闭，让它运行后断电，延长寿命。
   - 三角形接法有相序要求，如 U1–W2、V1–U2、W1–V2，接错会电流大、转矩小。
9. **“11 kW 及以上用星三角”**（`pages-data.js:113`、`pages.js:212`）：这是厂内经验。规范上能不能直接起动，看起动时母线压降和变压器容量（GB 50055 相关条款，**未取原文**）。建议改成“是否直接起动由供电容量决定，很多厂以 11 kW 为界”。
10. **断路器“D 曲线、1.5–2 倍”**（`pages.js:207`）：属于经验值，**未能证实**。建议补一句：电机回路更常用**电动机保护断路器**（GV2 / 3RV / DZ108 一类），整定值等于电机额定电流，可以同时代替热继电器。
11. **PLC 直接驱动 DC24V 接触器**（`info.js:14`、plcfr 练习）：要核对线圈功率。S7-1200 晶体管输出每点 0.5 A，CJX2 DC 线圈吸持功率可能有好几瓦，接近上限时要通过 KA 驱动，并在线圈上加二极管。
12. **急停**：要用带**直接断开动作**（强制断开）的常闭触点（IEC 60947-5-1 附录 K）；正规设备的急停回路接安全继电器，按停止类别 0 / 1 设计（ISO 13850 / GB/T 5226.1 9.2）。拍下急停后还必须重新给启动命令才能动，这一点练习里已经有了。
13. **续流二极管的副作用**：二极管会让电磁阀、接触器释放变慢。对响应速度有要求时，改用“二极管 + 稳压管”或 TVS。交流线圈用 RC 吸收或压敏电阻（原题目要求里提到了，页面里还没有写）。
14. **热继电器整定表注明系列**：PP.FRR 的档位和**正泰 NR2（对标施耐德 LRD）**一致，不是 JR36。JR36-20 的档位是 0.25–0.35、0.32–0.5、0.45–0.72、0.68–1.1、1.0–1.6、1.5–2.4、2.2–3.5、3.2–5、4.5–7.2、6.8–11、10–16、14–22，JR36-63 有 14–22、20–32、28–45、40–63。学员拿到 JR36 时档位会对不上，建议表头写明“NR2 系列”。

## 三、已核对无误

- **NPN / PNP 与公共端**：PNP 1M 接 0V、NPN 1M 接 +24V（`info.js:4,6`、`exercises.js:83–84,260,265`、PP.QZ 传感器题）。S7-1200 DC 输入两种接法都支持；电流方向的说明正确。
- **S7-1200 DC/DC/DC 端子**：L+ / M 是 CPU 电源，1M 是输入公共端，3L+ / 3M 是晶体管输出电源，输出高电平为 +24V（源型输出）。core.js 里 PLC / PLCR 的端子集合合理（PLCR 的分组已注明是简化）。
- **指示灯**：RUN/STOP 黄色常亮 = STOP、绿色常亮 = RUN；ERROR 红灯闪 = 组态 / 内部 / 存储卡错误，红灯常亮 = 硬件故障（来源同上面的 PLCTalk 手册引用）。PP.QZ 中 RUN/STOP 黄灯、ERROR 红灯两题的答案正确。
- **传感器线色**：棕 +、蓝 −、黑 信号；欧姆龙 E3Z-D61 是 NPN、E3Z-D81 是 PNP（Omron E3Z 样本，见上）。两线制传感器的漏电流和 3–5 V 压降说法合理。
- **导线颜色**：N 浅蓝、PE 黄绿专用（GB 7947-2010）；GB/T 5226.1 推荐的黑（动力）、红（交流控制）、蓝（直流控制）三行（`pages.js:149`）正确。
- **端子号**：接触器 A1–A2 线圈，主触点 1/L1–2/T1、3/L2–4/T2、5/L3–6/T3，辅助常开 13–14 / 43–44，辅助常闭 21–22 / 31–32；热继电器 95–96 常闭（串控制回路）、97–98 常开（报警）（ABB TF65/TF96：https://library.e.abb.com/public/3155f66b18434a5781f6d784ec858f46/2CDC106069D0202_Thermal%20overload%20relay%20TF65%20and%20TF96_VIDEO.pdf ）；中间继电器 11 公共、12 常闭、14 常开；时间继电器 55–56 / 67–68 属于“特殊功能（延时）”触点，指示灯 X1 / X2，按钮 1–2 常闭、3–4 常开。core.js 中 DEV 各设备的端子号都符合这些规则。说明：功能数字 5–6 / 7–8 表示特殊功能这一点出自 EN 50005 / IEC 60947-1 附录 L，**未取得原文**。
- **CJX2 选型表**：0910 / 1210 / 1810 / 2510 / 3210 / 4011 / 5011 / 6511 / 8011 / 9511 对应 AC-3 380 V 下 9 / 12 / 18 / 25 / 32 / 40 / 50 / 65 / 80 / 95 A，4 / 5.5 / 7.5 / 11 / 15 / 18.5 / 22 / 30 / 37 / 45 kW，与 CJX2 系列样本一致（第三方转载：https://viox.com/product/viox-cjx2-6511-ac-contactor ）。型号后缀 10 = 1 常开、01 = 1 常闭的说法正确。
- **热继电器档位 PP.FRR**：与正泰 NR2-25 / 36 / 93 样本一致（0.25–0.4 … 17–25、23–32、30–40、37–50、48–65、55–70、63–80、80–93）：https://bombeo.co/wp-content/uploads/2024/04/NR2-CHINT-FT.pdf
- **电流估算和星三角计算**：380 V 下约 2 A/kW 的经验正确，公式 I = P/(√3·U·cosφ·η) 正确。星三角时主接触器、三角形接触器、热继电器按相电流 0.58×In 选，星形接触器按 1/3×In 选（calcMotor 逻辑正确）；星形起动时绕组电压降为 1/√3，线电流和转矩都约为直接起动的 1/3（PP.QZ 第 168 行正确）。直接起动电流 5–7 倍正确。
- **控制回路接线**：点动、启保停（13–14 并在 SB2 上，FR 95–96 和 SB1 串在前面）、正反转（互锁用对方 21–22）、顺序启动（从 KM1 自锁触点后取电）、星三角（KT 55–56 控星形、67–68 控三角形，KM2 / KM3 互相用常闭互锁）的网络和试车逻辑都正确。主回路 QF→KM→FR→M 走线、对调两相反转、缺相判断正确。
- **PLC 类练习**：npn、pnp、two、combo、cyl、diode、relay、estop、plcfr 的线号网络和接法正确：二极管阴极接 +、急停常闭硬接线串在 KM 线圈回路、停止按钮接常闭时程序里用常开触点、程序互锁加硬件互锁。故障练习 f1–f5 的现象和预设故障对得上。
- **变频器**：R/S/T 进、U/V/W 出，电源接到 U/V/W 会损坏；换转向对调 U/V/W 或改参数；命令源（面板 / 端子 / 通讯）和频率源（面板 / AI / 通讯）相互独立，与 SINAMICS V20 的 P0700（1 = 操作面板，2 = 端子，5 = USS/Modbus）、P1000（1 = MOP，2 = 模拟量 1）一致（V20 精简操作说明 A5E52951737A AB 12/2024）。汇川 F0-02 的 0 = 面板、1 = 端子、2 = 通讯一致（仅查到 MD500 功能码表，**MD380 原文未取得**）。输出侧不要带载通断接触器的原理正确（https://clipsal.com/faq/fa22914 ）。安装间距“看说明书，一般约 100 mm”与 V20 的 100 mm 一致。
- **IP 规划**：同网段、不重复、/24 下最后一段不能是 0 或 255、掩码 255.255.255.0 都正确；练习表里预设的 4 处错误设计合理。
